# Dotfiles

My personal configuration files.

## Neovim

Neovim configuration is in `nvim/`.

### Requirements

* Neovim
* Git
* ripgrep
* clang / clangd
* Tree-sitter CLI

### Setup

Clone this repository, then copy or link the `nvim/` directory to the appropriate Neovim configuration directory for your operating system.

Start Neovim and lazy.nvim will install the configured plugins.
